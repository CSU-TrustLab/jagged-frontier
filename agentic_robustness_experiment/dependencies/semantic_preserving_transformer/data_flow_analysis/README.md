# Data Flow Analysis

Uses CodeQL to query Python source code databases. Must be run in Docker.

1. **Build database**: `build_database(repo_path, database_path, language)`
2. **Construct query string**: `line_variable_access_query(file_name, line_number)`
3. **Run query**: `run_query(database_path, query_string)` → `list[list[str]]`

Query_Results is used only for temporary files generated by CodeQL. 

## Example

```bash
docker run --rm -it -v "${PWD}:/app" -w /app semantic-transformer python data_flow_analysis/examples/example_query_db.py
```

## Available Queries

| Query | Arguments | Row Format |
| :--- | :--- | :--- |
| `line_variable_access_query` | `file_name, line_number` | `[varName, role]` - role is `"read"` or `"write"` |
| `line_calls_function_query` | `file_name, line_number` | `[callExpression, col]` - callExpression is the function being called, col is the character position on the line where the call starts |
| `points_to_same_object_query` | `file_name, name1, name2` | `[firstName, firstLine, secondName, secondLine, sharedObject]` - each pair is a name and its line number. sharedObject is the common value they point to. Returns empty if there is no shared object.|
